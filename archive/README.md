# Archived Templates

This directory preserves page templates for future use on the site:

- **`annual-reports.html`**: Template for annual reports, quarterly filings, and shareholder statements.
- **`news-releases.html`**: Template for corporate news releases, public statements, and media announcements.
- **`software.html`**: Template for software platforms, technical systems, and subsidiary directories.

When ready to reinstate any page, move the file back into `pages/` and add the corresponding link back to the directory table in `index.html`.
